Data Structure Justification:

The dashboard options are listed in a dictionary as they can correspond to their respective functions easier than any other format. It's also easier to separate text from function.
Most of the program's space is taken up by functions since a large part of the program's purpose is to call those functions to display PivotTables. A large part of the program
is also based on user input. The file that's loaded, the date range being filtered out, the function being called, and how to interact with those functions are all
based on what number the user inputs. The program is built to counteract invalid inputs so that it runs smoothly. Side note: please make sure the program can access
"sales_data_other.csv" since it isn't uploaded to Google Drive like the original sales_data file is.


Function Design:

Most of the functions just restructure a PivotTable around the option that the user chooses. They're not that different from each other -- just a few changes to the indexes or
columns, or rarely the aggregation function. The displayDashboard() function numbers each dashboard option and calls the corresponding function based on user input. The exit()
function actually doesn't do anything else but display text. The displayDashboard() function does the actual exiting by just returning nothing and ending the looping function.
The filterByYearRange() function can filter the data by year, so that it only displays what the user inputs. The loadFile() just prepares the data to be analyzed and adjusts to
the file that the user selects.

Control Flow:

This program primarily uses try-except to catch invalid inputs or errors. This way, the user has chances to reenter their input as many times as it takes to get the right one. 
It also stops the program from breaking when an invalid input is entered, saving the user from having to restart the program again if they make a mistake. These try-excepts cover
a variety of invalid inputs, like wrong numbers, letters when there aren't supposed to be letters, and empty inputs.

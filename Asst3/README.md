Data Structure Justification:

As my quiz from Assignment 1 stored questions and answers on a JSON file, I used a JSON file for this assignment as well. It works really well to keep track of each question
and all the individual answers corresponding to the questions. There's also a certain precision to it, since the questions and answers can be picked out using indexes.
Additionally, after having added five additional questions to the JSON file, the structure of the JSON file makes the questions and answers incredibly easy to read. Differentiating
the questions and answers from each other is quite simple.

Function Design:

The functions in webapp.py are meant to run the pages of the quiz game. They also store variables and the quiz questions/answers to display on said pages. The most notable variables
are score, highScore, and feedback. The score variable tracks the score the user has and displays it on the results page. The highScore variable is the result of keeping track
of all the user's historical scores and is used to display the highest one. The feedback variable is used to determine whether to flash green or red in the quiz box every time
the user submits an answer. This feature/variable was generated by the VSCode agent.

Control Flow:

I don't believe it's possible for users to trigger errors or for there to be invalid inputs. If the user doesn't choose an answer before submitting, then the quiz will just
count it as an incorrect answer and move on to the next question. I've also put the quiz through a lot of test cases, so there shouldn't be anything that could break it.

Use of AI:

The parts of the program that I used the most AI on was the individual requirements, namely the timer and dynamic feedback (red/green flashes). It was difficult to figure out
where to start with these features, so the VSCode agent was able to help me with them. There were also a few instances where the program ran into errors, and I used AI to help
find what was causing the errors. Most of the time, it was issues with naming conventions or incorrect formatting. As a result of using AI, there's now a feedback variable,
JavaScript scripts in the templates, and animations. AI is most prominent in webapp.py, quiz.html, and quizTimed.html.
